# 羽毛球实战视频剪辑工作台 (Badminton Studio Pro) — 去 AI 味与专业 NLE 质感重塑设计规范

## 1. 项目背景与改版目标

在之前的迭代中，剪辑器界面采用了类似 OpenAI Codex / ChatGPT 的暗黑极客主题（`#10a37f` 翠绿荧光、霓虹渐变、`#0c0c0e` 纯黑背景、大面积等宽代码字体、以及缺乏文字说明的纯图标按钮）。用户反馈界面“AI 味道太重”，缺乏真正专业视频剪辑软件的亲和力与易用性。

本设计规范旨在将 Web 剪辑界面全方位重塑为**类似 Apple Final Cut Pro / 剪映 Pro 的专业运动视频剪辑工作台**：
- **配色去 AI 化**：告别 ChatGPT 翠绿与黑客黑，转向 **Apple Pro 经典深空灰（`#1c1c20`）+ 苹果专业蓝（`#0a84ff`）+ 暖琥珀高光（`#ff9f0a`）**，质感沉稳、克制、耐看。
- **排版去代码化**：全面回归 Apple 系统级无衬线字体（`-apple-system, "SF Pro Display", "PingFang SC"`），仅在时间码处使用等宽数字，彻底消除“代码终端感”。
- **交互图文并茂**：核心按钮告别纯图标猜谜，采用“紧凑扁平图标 + 明确中文标识”的专业 NLE 规范（如“导入视频”、“导出比赛集锦”、“起点微调”、“保留本回合”）。
- **保留双主题适配**：深色调如专业剪辑暗房，浅色调如 macOS 原生工坊（`#f5f5f7` 原生银白）。

## 4. 关键交互与文案去 AI 化重构

| 模块 | 原版（重 AI 味 / 抽象极客） | 新版（专业 NLE / 业务自然语言） | 改进理由 |
| :--- | :--- | :--- | :--- |
| **应用标题** | `Badminton Studio` + Codex 图标 | `羽毛球比赛剪辑工作室 · Badminton Studio Pro` | 树立明确的运动视频专业工具定位 |
| **顶部状态** | 两个纯图标 + 绿色高亮徽章 | `保留: 23 处多拍回合 · 精华总长: 05分42秒` | 信息直白，无需鼠标悬停猜测 |
| **模式选择** | 3x2 紧凑小图标格子（仅图标和单字） | 带有中文名称与功能释义的标准卡片（按局分段、连贯纯享、9:16竖屏、主角独享、战术复盘、五佳高光） | 清楚明白每种模式输出什么视频 |
| **导出按钮** | 绿色渐变按钮 `导出` | Apple Pro 蓝按键 `⚡ 导出比赛集锦` | 动宾结构明确，专业感强 |
| **修剪操作** | `[<] [>]` 与 `-0.5` `+0.5` 符号堆砌 | `[⏮ 上一拍]` `[▶ 播放]` `[⏭ 下一拍]`，配有明确的 `起点微调` 与 `终点微调` | 贴合剪映与 FCP 用户习惯 |
| **保留开关** | 纯对勾图标 | `[✓ 保留本回合]` / `[⊘ 跳过本回合]` | 状态切换文字反馈一目了然 |
| **回合卡片** | 抽象的小圆角 Chip | 规整的 NLE 回合卡片，含回合序号、起止时标、时长、拍数、保留标记 | 像真实的工程轨道块一样易辨认 |

## 5. 技术实现与兼容性设计

1. **单文件内聚性**：更新位于 `scripts/ui/index.html`，保持 HTML/CSS/JS 单文件内聚打包，不增加额外构建链，保证 Windows `.bat` / `.exe` 与 Mac `.command` 一致的原生运行体验。
2. **硬件加速指示**：左下方保留显卡硬件编码检测标签（`Apple VideoToolbox (Hardware)` / `NVIDIA NVENC` / `Intel QSV` / `CPU Native`），显示工具硬实力但不做极客渲染。
3. **快捷键系统**：
   - `Space`：播放 / 暂停当前回合并支持循环预览。
   - `↑` / `↓`：上一个多拍 / 下一个多拍。
   - `[` / `]` 或 `I` / `O`：快速将当前播放帧设定为回合起点 / 终点。
   - `Delete` / `Backspace`：快速保留 / 跳过当前回合。

## 6. 验证与验收标准

1. **视觉去 AI 检查**：界面中彻底去除 `#10a37f` 绿色、霓虹渐变、纯暗黑 `#0c0c0e` 背景与无文字图标盲按区。
2. **功能完备性验证**：视频播放、起止点微调、按局筛选、导出各种模式、时间轴播放头拖拽均 100% 正常工作。
3. **响应式与多系统适配**：在 1440x900 以上桌面分辨率及 Windows / Mac 默认缩放下无滚动条溢出。
