羽毛球比赛剪辑工作室 · Badminton Studio Pro
Windows 使用说明

1. 安装 Python 3.10 或更高版本，并将 Python 添加到 PATH。
2. 安装 FFmpeg 并加入 PATH，也可将 ffmpeg.exe 放到本目录的 bin\ffmpeg.exe。
3. 双击 启动可视化剪辑软件_Windows.bat。首次启动会安装 NumPy 和 OpenCV，
   然后在 Edge、Chrome 或默认浏览器打开本地工作台。工作台有深色和浅色主题，
   使用 Apple Pro Blue 强调选中状态。
4. 选择视频或目录，扫描生成时间轴。可试听原声、微调起止点，并保留或跳过回合。
5. 默认输出多拍与接发秒杀候选。其他模式包括多拍纯享、居中比例裁剪、
   按手动站位标注筛选个人高光，以及按长回合与打法标注分类。
6. 修改过切点或标注后，用“按时间轴导出”。选中“帧级精剪”后会重新编码；
   默认流复制更快，实际切点受关键帧影响。

在 Windows 上可运行 打包Windows独立EXE程序.bat 构建可执行文件。
打包前可放入 bin\ffmpeg.exe，打包脚本会将它复制到发行目录。
也可以将 FFmpeg 安装到运行机器的 PATH。ZIP 提供源代码与启动器。

依赖、CLI 示例和提速选项见 README.md。
