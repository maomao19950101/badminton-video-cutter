一、Windows 快速启动方式（任选其一，100% 纯本地运行）

【方式 1：双击批处理脚本启动（推荐）】
1. 确保电脑已安装 Python 3.9+（安装时务必勾选 "Add Python to PATH"）。
2. 将 ffmpeg.exe 放置在软件目录下的 `bin\ffmpeg.exe`（或已配置在系统 PATH 环境变量）。
3. 双击 `启动可视化剪辑软件_Windows.bat`：
   - 首次运行会自动在您的 **Windows 桌面** 生成专属快捷方式【羽毛球比赛剪辑工作室.lnk】。
   - 自动启动本地高速服务并在系统 Edge/Chrome 中弹出**独立无边框专业工作台窗口**。
   - 全自动调用 Windows 显卡硬件加速（N卡 NVENC `h264_nvenc` / Intel QSV `h264_qsv` / AMD AMF `h264_amf`）。

【方式 2：一键打包成免安装独立 EXE 程序】
1. 双击运行 `打包Windows独立EXE程序.bat`。
2. 打包完成后，进入 `dist\羽毛球比赛剪辑工作室\` 文件夹，即可直接双击运行内嵌全部资源的 `羽毛球比赛剪辑工作室.exe`。

二、专业非编剪辑工作台（Pro NLE）设计与操作说明

软件彻底移除了老旧的 AI 绿光特效与极客晦涩图标，采用媲美 Apple Final Cut Pro / 剪映专业版的沉稳专业灰调（Slate Gray）与苹果专业蓝（Apple Pro Blue）设计语言：

1. 【左侧视频源与多模式控制坞】：
   - 视频源导入：点击 `[+ 添加文件]` 单选或多选比赛视频，或点击 `[📁 导入目录]` 批量导入。
   - 视频列表：清晰显示文件名、解析多拍总数（如 `41拍`）与当前活动标记（`当前对战` / `就绪`）。
   - 6 大实战集锦生成模式：
     (1) 【按局分段】（默认标准）：自动按比赛对局切分全部多拍精彩回合。
     (2) 【连贯纯享】：彻底剔除死球、捡球走动等待，整场紧凑纯享连续播放。
     (3) 【9:16 竖屏】：手机竖屏短视频智能裁剪居中无黑边导出。
     (4) 【主角独享】：指定主角球员出场时段独立集锦。
     (5) 【战术复盘】：发球接发一拍定音秒杀战术专项复盘。
     (6) 【五佳高光】：Top 5 极限拉锯多拍与慢镜重放精选。
   - 底部操作：点击 `[⚡ 导出比赛集锦]` 一键高速导出，支持随时点击 `[⏹ 停止剪辑任务]`。

2. 【中间监视器与专业走带控制（Transport Controls）】：
   - 当前回合状态指示：显示回合编号（如 `#01`）、精确起止时间码（如 `00:00.0 – 01:30.0`）及持续秒数。
   - 具名中文操作按键：
     • `[⏮ 上一拍]` / `[⏭ 下一拍]`：前后切换回合。
     • `[▶ 播放本回合]`：高亮蓝色按钮，循环播放当前多拍片段。
     • `[◀ -0.5s]` `[[← 起点微调]` `[+0.5s ▶]`：以 0.5 秒为步长精准微调起拍点，杜绝剪掉发球前摇。
     • `[◀ -0.5s]` `[→] 终点微调]` `[+0.5s ▶]`：精准微调死球点，杜绝走动废片。
     • `[✓ 保留本回合]` / `[⊘ 已跳过本回合]`：一键决定是否将当前多拍纳入最终成片。

3. 【交互式多段切片时间轴】：
   - 蓝色块代表保留回合，灰色块代表跳过回合，白色高亮代表当前选中的播放回合，红色指针指示当前播放头。
   - 直接用鼠标点击时间轴任意位置，即可快速跳转定位并高亮对应多拍。

4. 【对局筛选与卡片矩阵】：
   - 对局标签页：按对局即时过滤（如 `全部 (41)`、`第01局 (10拍)`、`第02局 (18拍)`、`第03局 (13拍)`）。
   - 快速批量操作：`[✓ 全部保留]`、`[☆ 只留超长多拍(≥15秒)]`。
   - 响应式回合卡片：每张卡片标明多拍编号、标签（超长拉锯 / 激烈对战）、起止毫秒与对局归属，点击即可选定播放。

5. 【全键盘快捷键支持】：
   - `空格键 (Space)`：播放 / 暂停当前多拍回合
   - `↑` / `↓` 或 `←` / `→`：切换上一拍 / 下一拍
   - `I` 键：将当前播放头位置设为回合【起点】
   - `O` 键：将当前播放头位置设为回合【终点】
   - `Backspace` / `Delete` 键：快速切换当前回合【保留 / 跳过】
