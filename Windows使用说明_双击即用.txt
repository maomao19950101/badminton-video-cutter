一、Windows 快速启动方式（任选其一）

【方式 1：直接双击运行（推荐）】
1. 确保电脑已安装 Python 3.9 及以上版本（安装时勾选 "Add Python to PATH"）。
2. 将 ffmpeg.exe 放置在软件目录下的 `bin\ffmpeg.exe`（或已配置系统环境变量）。
3. 直接双击 `启动可视化剪辑软件_Windows.bat`，软件将自动安装所需轻量依赖（numpy, Pillow）并弹出可视化主界面。

【方式 2：一键打包成免安装独立 EXE 程序】
1. 双击运行 `打包Windows独立EXE程序.bat`。
2. 打包完成后，打开 `dist\羽毛球AI剪辑大师\` 文件夹，双击 `羽毛球AI剪辑大师.exe` 即可在任何 Windows 10 / 11 电脑上直接运行！

------------------------------------------------------------------------
二、核心操作流程

1. 【全自动一键出片】：
   - 点击左上角「➕ 添加视频」或「📁 添加文件夹」导入录制的比赛视频。
   - 右上角点击绿色大按钮「🚀 一键全自动剪辑并输出视频」。
   - 软件会自动识别球员球衣换人分出「第01局 / 第02局 / 第03局」，剔除所有捡球、换球死球时间，并无损输出高清切片。

2. 【时间轴可视化微调 & 双画面预览】：
   - 点击任意回合色块或下方列表行，界面中部会同时展示该球的「🟢 回合起点画面」与「🔴 回合终点画面」。
   - 支持直接用鼠标拖拽时间轴色块左右边缘微调起止秒数，或点击 `-1.0秒(剔除换球)` / `+1.5秒(延长救球)` 按钮。
   - 支持按空格键（Space）直接在软件窗口内连续播放当前回合画面。
   - 支持「✂️ 拆分为新一局」「🔗 合并至上一局」及双击切换「✅ 保留 / 🚫 剔除」。
   - 微调完成后点击「🎬 导出当前时间轴视频」即可极速输出！

3. 【六大剪辑输出模式（支持自由多选）】：
   - ⭐ 经典全能合集（默认勾选）
   - ⏱️ 一刀不剪·纯享紧凑版（合成连贯无死球长视频）
   - 📱 竖屏短视频模式（9:16 手机全屏自动居中裁剪）
   - 🌟 个人高光 Solo 视角（指定近端/远端左右半场站位）
   - 🎓 发接发前三拍切片（截取开球前 3.5 秒）
   - 💥 球风分类视频库（自动归类至重杀突破 / 多拍拉锯 / 平抽快攻）
